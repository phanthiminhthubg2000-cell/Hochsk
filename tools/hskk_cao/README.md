# Luyện HSKK Cao cấp (/hskk-cao)
- qbank.py: 123 câu hỏi 回答问题 (đề thi thật + câu hỏi gom từ các kỳ thi). sa1–sa6.py: bài mẫu + dàn ý tự viết (【】 = cụm hay).
- seg.py/seg2.py: tìm đoạn 听后复述 trong file nghe gốc theo khoảng lặng → segs2.json. ext.py/tr.py: đọc đề, chép lời. retell_text.json: lời đã soát.
- enrich.py: dịch, ý chính, từ khoá cho đoạn nghe. qa_vn.py: dịch bài mẫu, dàn ý, cụm từ.
- Kết quả: public/hskk-cao/{retell,qa,read}.json + audio/*.mp3
